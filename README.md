### Use node version 20.14.0

### 1. Clone the Repository

```bash

https://github.com/GITANSHU7/websocket.git
````
### 2. (a) Run application (backend)

```bash

cd backend
npm install
npm start
```
### 2.(b) Run application (frontend)

```bash
cd frontend
npm install
npm run dev
```
## Application will up and running at http://localhost:5173/
